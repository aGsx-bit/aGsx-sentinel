# API Recon Reference Guide

## Toolsets & Commands

### Static Bundle Analysis
- `grep -oE "['\"][/][a-zA-Z0-9_/.-]+['\"]" <bundle.js>`: Quick endpoint regex extraction.
- AST parsing via script to extract declared request objects, Axios instance baseURLs, and headers.

### Common Frontend Routing Patterns
- Vue Router: `routes: [{ path: '/...', component: ... }]`
- React Router: `<Route path="..." element={...} />`
- Next.js: App router directories or `pages/` convention.

### Interception & Mocking Strategy
When observing Single Page Applications (SPAs) without credentials:
1. Intercept authentication check endpoints (`/api/auth/me`, `/api/user/profile`).
2. Return a valid JSON response with standard user claims:
   ```json
   { "code": 200, "data": { "id": 1, "username": "admin", "role": "admin" } }
   ```
3. Allow the SPA router to transition from the login redirect to authenticated views.
4. Record all subsequent API calls generated by rendered tables, analytics dashboards, and management panels.
